# TagVerify Admin Portal

Planned web app (Next.js + Firebase, the same stack as expense-manager). It will be built after the dealer MVP.

## Planned modules

1. **Company onboarding:** name, logo, COP number, COP validity
2. **QR generation:** pick company and product type, set quantity, auto-generate serial numbers, print a sticker sheet PDF
3. **Dealer creation:** name, address, email, mobile, company, passing and registration location
4. **Certificate generation:** upload a QR to open the same form dealers use
5. **Edit and delete certificates:** deleting one resets its QR to unused, so it can be certified again

It will also host the public certificate page that each QR's URL points to.
